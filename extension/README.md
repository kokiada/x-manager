# x-manager 実行役（Chrome 拡張）

x-manager コンソールの「実行役」です。アカウントごとの X セッションを持ち、
コンソールからの指示で X への実操作を行います。

## 今の段階（実行の実装済み）

- Web アプリ ⇔ 拡張の通信プロトコル（`src/executor/protocol.ts` が正本）
- ハンドシェイク（接続確認）と連携アカウント一覧の応答
- 連携アカウントのセッション保管庫（`chrome.storage.local`）
- **実行そのものも実装済み**：投稿・削除・いいね／リポスト／ブックマーク／
  フォロー・アカウントチェック・サーチバンチェック・ポスト分析・通知/DM取得
  を、X Web版内部API（GraphQL）で呼ぶ。セッション切替は直列化して Cookie
  の取り違えを防ぐ。query ID はバンドル走査で生きたものを探す。
- ただし実アカウントでの疎通確認はまだできていない（開発環境に実アカウントが
  無いため）。下の「実アカウントでの試運転」で初めて確認する。

## 読み込み方（開発版）

1. Chrome で `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこの `extension/` フォルダを選ぶ
4. ツールバーの拡張アイコンから「x-manager 実行役」を開く

## アプリ版（Electron）での読み込み

アプリ版（`npm run dist:win` で作る exe）では、拡張はアプリ起動時に
自動で読み込まれます。Chrome への手動インストールは不要です。
連携画面はアプリのメニュー「拡張」→「連携画面を開く」、または
設定画面の「拡張の連携画面を開く」ボタンから開けます。登録した
auth_token は Electron 側の拡張ストレージ（ユーザーのPC内）にだけ
保存されます。詳しくは `docs/APP_BUILD.md` を参照してください。

## アカウントの連携

1. ポップアップで x-manager のアカウントIDと、そのアカウントの `auth_token`（40文字の Cookie 値）を入力して「連携する」
2. x-manager 側で「設定 → 実行方法（X連携）」を開き、「Chrome 拡張」を選んで保存
3. 「接続を確認」で「接続済み」になれば準備完了

`auth_token` はこのブラウザの `chrome.storage.local` にだけ保存されます。
Web アプリには送られず、ネットワークにも出ません。解除はいつでもポップアップからできます。

### auth_token の取り方

X にログインした Chrome で、開発者ツール（F12）→ アプリケーション → Cookie →
`https://x.com` → `auth_token` の値をコピーします。

## 対象ページについて

content script は今のところ次のページでだけ動きます。

- `http://localhost/*`、`http://127.0.0.1/*`（開発・プレビュー）
- `https://*.muse.ai/*`（公開版）

アプリを別の場所で公開する場合は `manifest.json` の `content_scripts[].matches`
にそのオリジンを追加してください。

## 実アカウントでの試運転（初めての確認手順）

1. **別プロファイル推奨**：Chrome で新しいプロファイルを作り、その中で
   拡張を読み込む。実行中は拡張が x.com の Cookie を切り替えるため、
   普段使いのプロファイルの x.com タブと混ぜないこと。
2. 拡張を読み込み、ポップアップで**サブアカウント**（本アカ以外が安全）の
   auth_token を連携する。
3. x-manager を開き、設定 → 実行方法（X連携）で「Chrome 拡張」を選ぶ。
4. まず**アカウントチェック**（アカウント一覧の「チェック」）を実行する。
   フォロワー数が表示されれば、セッションと内部APIの疎通は通っている。
5. 次に**テスト投稿**（短い本文・メディア無し）を1件だけ実行する。
   - 成功すれば投稿・削除まで試す。
   - 「トランザクションIDを付けて送っても拒否された」と出たら、ヘッダ付きでも
     Xに拒否された状態。アカウントの制限か、X側の仕様変更の可能性がある。
   - 「トランザクションIDの生成に失敗したためヘッダ無しで送り、拒否された」と
     出たら、生成器がシェルを取れていない状態。拡張を再読み込みしてから再試行し、
     それでも同じなら開発者に伝えてください（ログイン済みタブからの取得に切替えます）。
   - 「query ID が見つかりませんでした」と出たら、Xの更新で ID が変わった
     状態。拡張の更新が必要です。
6. 問題なければ、いいね・フォロー・サーチバンチェックを順に試す。
   サーチバンチェックは X の検索制限（15分50回）に注意。

## 注意

- X の画面操作の自動化は X の利用規約上グレーな領域です。ロック・凍結の
  リスクがあることを理解したうえで、自己責任で使ってください。
- 拡張が読み込まれていない Chrome では、実行方法が「拡張」の操作は
  エラーになります（シミュレータには黙って戻りません）。
- 実行中は x.com のタブを操作しないこと。Cookie が切り替わるため、
  開いているタブのアカウントが入れ替わることがあります。
