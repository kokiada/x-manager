x-manager 実行役

アカウントの auth_token はこのブラウザの中（chrome.storage.local）にだけ保存されます。どこにも送信されません。

ログイン中のアカウントを取り込む

X にログインしたこの Chrome から、auth_token をコピーせずに連携できます。トークンの値は画面に出ません。

手入力でアカウントを追加する

取り込みは、X にログイン中のアカウントが対象です。複数アカウントを使う場合は、X でアカウントを切り替えてから同じ操作を繰り返してください。

手入力で登録する場合は、auth_token は X にログインしたブラウザの Cookie から取得します（開発者ツール → アプリケーション → Cookie → https://x.com）。

連携しただけではアプリの一覧には増えません。アプリのアカウント画面で「拡張の連携を取り込む」を押してください。
