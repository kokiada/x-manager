# x-manager 設計方針（XBoardクローン）

調査の全文は [xboard-research.md](./xboard-research.md) を参照。本書はクローンの設計判断をまとめる。

## 1. プロダクト概要

- XBoard（x-board.net）のクローン。X（旧Twitter）の複数アカウントを一元管理するWebアプリ。
- 品質目標：売り物にできるレベル。
- PC・スマホ両対応（レスポンシブ＋PWA）。本家はPC専用デスクトップアプリだが、本プロジェクトはブラウザで動くことが要件。

## 2. 本家のコア原理（調査結果）

- X APIを使わない。アカウントごとに分離したブラウザセッションで直接Xにログインし、全操作をブラウザ経由で行う。
- アカウントごとに個別プロキシ設定、auth_tokenによるトークンログイン、ログイン情報は端末内にのみ保存。
- 主要機能：一括投稿（テンプレート/ランダム文言/ツリー/予約/自動投稿）、一括いいね・リポスト・ブックマーク＋自動操作、サーチバンチェック、アカウントチェック（状態＋通知/DM件数＋フォロワー数）、ポスト分析・追跡・フォロワー推移、CSV管理、端末同期、リモート操作。

## 3. 実現可能性とアーキテクチャ判断（重要）

ブラウザ上のWebアプリだけでは、本家のコアである「x.comへのauth_token Cookie注入」「アカウント別プロキシ経由の実ブラウザ操作」はブラウザのセキュリティモデル上そのまま再現できない。そこで実行層を分離する：

- **管理コンソール（Webアプリ本体）**：アカウント台帳、グループ、プロキシ割当、状態管理、一括操作のキューとロジック（順序・間隔・テンプレート展開・ツリー生成・予約）、バンチェック手順、分析、CSV入出力、同期。本家の仕様数値（間隔1〜60秒、テンプレート2,000件、ランダム文言[Random1]〜[Random2000]、メディア上限など）を忠実に実装する。
- **Executor（実行層インターフェース）**：操作を実際にXへ届ける層を差し替え可能にする。初期出荷はシミュレータExecutor（デモデータで全フローが動く）。将来、ローカルエージェント／ブラウザ拡張／デスクトップラッパーが同じインターフェースで実操作を担当できる。
- **データは端末内保存**（IndexedDB）を基本とし、本家の「サーバーに送信しない」思想を踏襲。端末同期は暗号化エクスポート/インポートとして設計する。

この分離により、UIとロジックは本家同等レベルまで作り込め、実操作の接続は後から差し替えられる。

## 4. 技術スタック（案）

- Vite + React + TypeScript（SPA、PWA対応）
- 状態管理：軽量に（React Context + hooks、必要に応じZustand）
- データ：IndexedDB（Dexie）
- スタイル：CSS変数によるデザイントークン＋モバイルファーストのレスポンシブ
- テスト：Vitest（ロジック層中心）

## 5. 画面構成（案）

1. ダッシュボード（アカウント状態サマリ、要対応アラート）
2. アカウント一覧（グループ絞り込み、状態バッジ、プロキシ表示、チェック実行）
3. アカウント詳細（セッション/プロキシ/auth_token管理、個別指標）
4. 一括投稿（テンプレート、ランダム文言、ツリー、予約、メディア）
5. 一括操作（いいね/リポスト/ブックマーク、自動操作ルール）
6. バンチェック（サーチバン実行・結果一覧、定期チェック）
7. 分析（ポスト分析、ポスト追跡、フォロワー推移）
8. 通知/DM集約
9. データ管理（CSV入出力、バックアップ/同期）
10. 設定（プラン、同時保持数、定期チェック）

## 6. タスク分担（案）

- **ゆい（プレイングマネージャー）**：全体設計・デザインシステム、アプリシェル/ナビゲーション、アカウント管理（台帳・グループ・プロキシ・CSV）、一括投稿エンジンと画面、統合・レビュー・品質管理
- **ガッツ**：アカウントチェック＆サーチバンチェックのワークフローと判定ロジック、分析（ポスト分析・追跡・フォロワー推移）、自動投稿・自動操作エンジン、通知/DM集約

分担は案。ガッツの希望を聞いて調整する。

## 7. マイルストーン

1. M1: 基盤（スキャフォールド、デザインシステム、データモデル、アカウント管理CRUD＋グループ＋プロキシ割当）
2. M2: 一括投稿（一括/ツリー/予約/テンプレート/ランダム文言）＋シミュレータExecutor
3. M3: チェック系（アカウントチェック、サーチバンチェック、定期実行）
4. M4: 一括操作・自動操作、分析、通知/DM集約
5. M5: CSV・同期、PWA仕上げ、品質改善（売り物レベルへの磨き込み）
