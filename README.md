# x-manager

X（旧Twitter）の複数アカウントを一元管理する Web アプリ。XBoard（x-board.net）のクローンとして、ブラウザで動作する管理コンソールを目指すプロジェクトです。

設計方針は [docs/DESIGN.md](./docs/DESIGN.md)、本家の調査結果は [docs/xboard-research.md](./docs/xboard-research.md) を参照してください。

## アーキテクチャの要点

- **管理コンソール（本アプリ）**: アカウント台帳、グループ、プロキシ割当、状態管理、一括操作のロジックを担う。本家の仕様数値（投稿間隔1〜60秒、テンプレート2,000件、ランダム文言 `[Random1]`〜`[Random2000]` など）を忠実に実装する。
- **Executor（実行層）**: 実際のX操作を担う差し替え可能なインターフェース（`src/executor/`）。現在はシミュレータ実装で全フローがデモデータで動作する。将来、ローカルエージェント／ブラウザ拡張などが同じインターフェースで実操作を担当できる。
- **データは端末内保存**: IndexedDB（Dexie）に保存し、サーバーへ送信しない。本家の思想を踏襲。auth_token も端末内にのみ保存し、UIでは常にマスク表示する。

## 技術スタック

- Vite + React + TypeScript（SPA / PWA basics）
- データ: IndexedDB（Dexie + dexie-react-hooks）
- ルーティング: React Router（HashRouter）
- テスト: Vitest（ロジック層）

## CSV形式（アカウント整理 / M5）

- **アカウントCSV**: 列は `グループ名,グループID,アカウント名,アカウントID,XログインID,Xログインパスワード,2FA認証トークン,AuthToken,プロキシ表示名,メモ1`（1行=1アカウント、行順=グループ内の並び順）。書出はUTF-8（BOM付き）、取込はUTF-8とShift_JISに対応。見出し行を変更したCSVは取り込めない。グループIDが空欄ならグループ名で新規作成（同名があれば再利用）、アカウントIDが空欄なら新規アカウント。ログイン情報・AuthToken・プロキシ・メモの列は新規アカウントにのみ適用され、既存アカウントの行に入力するとその行はエラー（スキップ）になる。既存アカウントは表示名・所属グループ・並び順のみ変更でき、CSVではアカウントを削除できない。取込前にプレビュー（行ごとの作成／更新／スキップ結果と理由）が表示され、確認してから適用する。パスワードやAuthTokenが平文で含まれるため取り扱い注意。

## CSV形式（M2）

- **テンプレートCSV**: 列は `no,text,title,images,group`（1行=1テンプレート）。`images` はカンマ区切りのファイル名（最大200件、`image1`〜`image4` の分割列も可）、`title` は管理用で50文字まで、`group` は20文字までで無い名前は新規作成。見出しは日本語（番号／本文／タイトル／画像／グループ）でも可。取込は「空き番号に追加」（`no`列無視）か「CSVのnoで上書き」（同じ `no` は後の行が優先）。アンケートとツリーの続きはCSV対象外で、上書きしても保持される。
- **ランダム文言CSV**: 列は `no,word`（1行=1文言）。`no` は1〜2000で範囲外はスキップ、同一番号の重複は1つに集約。`word` が空欄の行は、その番号の文言リストを空にする。取込は「番号の文言に追加」か「番号の文言を置き換え」。
